# Colors for HRApop cell type visualizations 
The `data` folder contains JSON and CSV versions of the color schemes used for the top cell types in the supertree. `as-colors.csv` contains colors for anatomical structures.

The HRApop color scheme uses [[Color Brewer](https://colorbrewer2.org/#type=qualitative&scheme=Paired&n=10)](https://colorbrewer2.org/#type=qualitative&scheme=Paired&n=10) while the AS color scheme uses [https://colorbrewer2.org/#type=qualitative&scheme=Set3&n=10](https://colorbrewer2.org/#type=qualitative&scheme=Set3&n=10).
